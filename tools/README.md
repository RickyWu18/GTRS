# tools/ — 離線工具鏈

統一以 Python 撰寫。**不屬於網站執行路徑**——前端仍為純靜態，不需任何建置步驟即可執行。

計畫書 4.3 的「純前端」限制其目的是保障貢獻者的工作流程（新增內容不需安裝工具、
commit 即生效），不禁止 repo 中存在由離線腳本產生的檔案。`generated/` 下的產物
由 CI 在 push 後重建，貢獻者無須感知其存在。

## 管線選型待重新評估

計畫書 7.2 建議的本地方案（Surya、Texify、本地 VLM）**假設有可用 GPU**。
本機無 GPU，故該節的候選工具表需重新評估，選項為 CPU 可跑的
pix2tex + Tesseract（公式準確率較低）或改走雲端。

實際落差待 W0.7 抽樣測試揭示。

## 硬性規則

**一切機器產出一律標記 `status: draft`**，無論來自 OCR、公式辨識或視覺語言模型。
唯有經人眼逐字對照掃描原文核對後方可升級（計畫書 9.5）。

VLM 會對辨識不清的符號進行「補全」，產生語法正確、外觀合理但內容錯誤的輸出。
由於本專案排除數值驗證，此類錯誤缺乏自動偵測手段。
