取 11 條真實公式，涵蓋判準所列的全部特徵。**取樣避開 pdf 113–145**（M1 標的章

## 2　演算法：三個非做不可的設計決定

取代的對象是 `symbols.yaml` 的 **`latex` 欄位**（`\rho`），不是 key（`rho`）。
5.4.2 已載明「`latex` 欄位保存該符號的完整 LaTeX 寫法，是 F1 比對的實際依據」。

以下三點若任一沒做，都會靜默產生錯誤輸出——不報錯，只是壞掉。

**一、單次左到右掃描，絕不回頭重掃已輸出的內容。**
輸出的 `\htmlData{sym=U_HMR}{U_{HMR}}` 本身含有看起來像符號的文字（`U`、`R`、`HMR`）。
若分多趟取代，第二趟會把自己產生的標記再包一層。

**二、最長優先。**
`U_{HMR}` 必須先於 `U` 被比中，否則 `U` 會比中 `U_{HMR}` 的開頭。

**三、不是符號的 LaTeX 巨集，整個命令名一次複製完。**
若逐字元前進，單字元 key `s` 會比中 `\sin` 裡的 `s`，產生 `\htmlData{sym=s}{s}in`。
`\text{}`／`\mathrm{}` 等群組另以大括號配對整段跳過。

核心函式（W2.7 實作時移入 `js/render/symbols.js`）：

```js
export function annotate(latex, symbols) {
  const syms = [...symbols].sort((a, b) => b.latex.length - a.latex.length);
  let out = '', i = 0;
  outer:
  while (i < latex.length) {
    for (const cmd of ['\\text', '\\mathrm', '\\operatorname', '\\textbf', '\\mathbf']) {
      if (latex.startsWith(cmd, i)) {
        let j = i + cmd.length;
        while (latex[j] === ' ') j++;
        if (latex[j] === '{') {
          const end = matchBraceGroup(latex, j);
          if (end > 0) { out += latex.slice(i, end); i = end; continue outer; }
        }
      }
    }
    let hit = null;
    for (const s of syms) if (latex.startsWith(s.latex, i)) { hit = s; break; }
    if (hit) {
      let end = i + hit.latex.length;
      if (latex[end] === '^') {                       // 見第 3 節
        let k = end + 1;
        if (latex[k] === '{') { const e = matchBraceGroup(latex, k); if (e > 0) k = e; }
        else if (latex[k] === '\\') { k += 2; while (/[a-zA-Z]/.test(latex[k] ?? '')) k++; }
        else if (k < latex.length) k += 1;
        end = k;
      }
      out += `\\htmlData{sym=${hit.key}}{${latex.slice(i, end)}}`;
      i = end;
      continue;
    }
    if (latex[i] === '\\') {
      let j = i + 1;
      if (/[a-zA-Z]/.test(latex[j] ?? '')) { while (j < latex.length && /[a-zA-Z]/.test(latex[j])) j++; }
      else j = i + 2;
      out += latex.slice(i, j); i = j; continue;
    }
    out += latex[i++];
  }
  return out;
}
```

**KaTeX 需要 `trust: true`**，否則 `\htmlData` 被靜默忽略（實測 `data-sym` 出現 0 次）。
另建議 `strict: false` 以關閉 `htmlExtension` 的警告。

## 3　標註必須吸收緊接的上標，否則會改變排版

這一項是實作過程中發現的，**判準沒有列，但不做就錯**。

`\omega_n^2` 若標註成 `\htmlData{sym=omega_n}{\omega_n}^2`，指數會從「與下標疊在一起」
變成「掛在整組之後」。連帶效果是 `\left[ \right]` 的自動尺寸跟著變——整條式子的
括號高度都不一樣了。

修法是比中符號後，把緊接的 `^` 群組一併包進去：`\htmlData{sym=omega_n}{\omega_n^2}`。

**只吸上標不吸下標。** 下標若不在符號的 `latex` 裡，代表那是另一個符號或字典有缺，
一併吞掉會把 `U_{HMR}` 錯報成 `U`。

修正後重測，11 條的**可見字元序列與原子類型序列（`mord`／`mbin`／`mrel`…，決定 TeX
間距）與未標註版本完全相同**——標註不改變排版。

## 4　代價：一條轉錄書寫規則

**規則：同時有上下標時，下標寫在前。**

| 寫法 | 解析 | 可標註 | 渲染 |
|---|---|---|---|
| `\omega_n^2` | ✓ | ✓ | 兩者**完全相同** |
| `\omega^2_n` | ✓ | ✗ | |

`\omega^2_n` 的 `\omega_n` 不是連續子字串，比對不到。兩種寫法渲染結果完全相同，
故這條規則**沒有視覺代價**，純粹是書寫順序的約定。須寫入 W4.0 的 SOP。

### 帶撇號的符號是例外，且有視覺代價

| 寫法 | 解析 | 可標註 | 可見字元 |
|---|---|---|---|
| `\Omega'_R^2` | **✗ Double superscript** | — | 不可用 |
| `\Omega'^2_R` | ✓ | ✗ | `Ω R ′2`（撇號與 2 併為一組上標，**最接近原文外觀**） |
| `{\Omega'_R}^2` | ✓ | ✓ | `Ω R ′ 2`（2 另起一層，掛在整組之後） |

撇號在 TeX 中本身就是上標，故「下標在前」的規則對它無效——`\Omega'_R^2` 直接是
解析錯誤。唯一可標註的寫法 `{\Omega'_R}^2` 與原文外觀有**可見差異**。

**建議：帶撇號且帶指數者，優先忠於原文寫 `\Omega'^2_R`，放棄該處的標註。**
理由是失效是局部且優雅的：

- **F2（被哪些公式使用）不受影響**——它由 `lhs`／`rhs` 清單推導，與標記無關
- **F1（hover 提示）僅該次出現失去掛載點**，同一符號在該式其他位置仍可 hover

以忠實轉錄換一個 hover 掛載點，符合本專案「轉錄不是重寫」的取捨。此項須在
W2.2 一併確認，並寫入 SOP。

## 5　順帶浮現的 G3 待決事項

5.4.2 的重音規約只給了單點與單槓的例子（`\dot{p}` → `p_dot`、`\bar{c}` → `c_bar`），
**沒有涵蓋雙點，也沒有規定重音與下標的先後**。本次測試資料暫用：

| 原文符號 | 暫用 key | 未定之處 |
|---|---|---|
| $\ddot{X}_{CG}$ | `X_CG_ddot` | 雙點的字尾寫法未規定 |
| $\ddot{\beta}_m$ | `beta_m_ddot` | 重音與下標孰先孰後未規定 |
| $\Omega'_R$ | `Omega_R_prime` | 撇號的字尾寫法未規定 |

三者皆屬 **W2.5 key 命名規約實例化**（G3）的範圍，本文不裁定。
此處的暫用值僅供 W2.1 測試，不得視為定案。
