## 2　五類結構

### 2.1　分段／條件式　—— 可表達，但用法需澄清

**原文不使用 cases 區塊。** pdf 188 寫的是獨立一行的散文條件：

```
if  h_Gn > 0          F_Gxn = F_Gyn = F_Gzn = 0
```

而 5.3.2 的設計是「分段函數以 `\begin{cases}` 寫在單一 `latex` 字串內」。
若照 5.3.2 改寫成 cases，等於**重組原文的呈現結構**，違反「轉錄，不是重寫」。

兩種寫法都能渲染（已實測）。**澄清：`kind: piecewise` 只用於原文本身即以分段形式
呈現者；原文寫成散文條件者，轉錄為 `single` ＋ `\text{if }…`，條件中的符號仍入
`condition_symbols`。** 這是用法約定，不是 schema 變更。

### 2.2　方程組　—— 可表達，無缺口

pdf 275 的 Roll／Pitch／Yaw 三式，原文本身就編號「1. Roll Equation／2. Pitch
Equation／3. Yaw Equation」，直接對應 5.3.2 的 `group.order`。平坦多筆加 `group`
標記可行，三式皆可渲染。同頁的積分式 `p = \int \dot{p}\,dt` 亦無問題。

### 2.3　矩陣與向量式　—— 可表達，無缺口

pdf 184 的 `[T_{B21}][\Omega] \times [\ ] = [\dots]` 以 `\begin{bmatrix}` 渲染成功。
5.3.2 所稱「不需新結構」成立，`shape: matrix` 僅供檢查腳本區分。

> 本項的 `latex` 為示意，未逐字精確轉錄——W2.2 驗的是表達力，不是轉錄正確性。

### 2.4　跨頁續行　—— **實際案例與 schema 的假設不同**

5.3.2 為「單一式子跨頁」設計了 `pdf_pages: [101, 102]`。但本次找到的唯一案例是
**小節層級的續行**：pdf 188 的「B. Gear Oleo Force」在 pdf 189 標
「B. Gear Oleo Force (Contd)」續寫，**每一條式子都完整落在單一頁面內**。

這種連續性由既有的 `section` 欄位已可表達，不需要 `pdf_pages`。

**本次 5 頁抽樣未發現任何單一式子被頁面邊界切開。** `pdf_pages` 為選填，
保留不花成本；其必要性待 P4 遇到真實案例時再確認。

### 2.5　同一量之改寫版本（`relates_to`）　—— 可表達，但案例的 `kind` 與預期不同

> **2026-09-26 補測。** 初測（2026-09-25）未找到案例，判準當時記為未達成。

原以為 pdf 250 的 `l_{WP} ← l'_{WP}` 是，細看後不是——那是一條真正的座標轉換
計算式，兩者的關係已由 `rhs` 表達，F2 自然涵蓋，不需要 `relates_to`。

確認的案例來自第 4 節撞到的 Subsystem 7A／7B。兩章各有一組 LANDING GEAR
LOCATIONS 三式，**逐字相同**：

| | 7A（pdf 176／A-108）Present Sigma 8 Model | 7B（pdf 188／A-120）Unused Bell Model |
|---|---|---|
| | `X_n = SL_{CG} - SL_{G_n}` | 同 |
| | `Y_n = BL_{CG} - BL_{G_n}` | 同 |
| | `Z_n = WL_{CG} - WL_{G_n}` | 同 |
| | Where: n = 1, nose gear; = 2, right gear; = 3, left gear | 同 |

同頁的齒輪伸放式亦近乎相同（7A pdf 177 作 `D_{MG} = q_F[D_{o_{MGD}}(t) + DPOD]`，
7B pdf 188 以小括號代方括號），呼應 W2.3 所見「7A／7B 共用 29 個 key、其中 25 個
描述完全相同」。

**`kind` 應為 `same_as`，不是初測預期的 `supersedes`。** `supersedes` 適用於改寫版本
取代舊版本；此處是同一式在兩章重出，兩式本身無新舊之分（新舊之分在**模型**層級，
記於 `modules.yaml` 的章名，不在式子層級）。

實測結果（`scratchpad/w21/relates.mjs`）：六筆條目的 `latex` 全部渲染成功、
F1 掛載點各 3/3，`relates_to: [{kind: same_as, target: eq-7A-gear-loc-x}]` 三筆
結構完整、target 均可解析。**schema 裝得下，不需新增欄位。**

一項性質須記錄給 W2.8：**`relates_to` 是單向欄位。** 本例只有 7B 的條目指向 7A，
7A 不指回。`same_as` 語意上對稱，但 schema 不強制雙向、亦無反向索引，因此
由 7A 的頁面看不到「7B 有同一式」，除非渲染層自行建立反向索引。
這是既有設計的性質而非缺陷——要求雙向會使 `relates_to` 變成必須成對維護的欄位。

## 3　W0.7 標記的 `schema_gap` 候選，實測後不是 gap

pdf 250 的方括號上方標 `→1`／`→0`：

```
l_WP = l'_WP cos α_WFS ⌊cos β_F⌋^(→1) − M'_WP cos α_WFS ⌊sin β_F⌋^(→0) − N'_WP sin α_WFS
```

四種標記寫法皆可渲染，其中 `\overset` 最接近原文位置（`→1` 在括號正上方）：

```latex
\overset{\rightarrow 1}{\left\lfloor \cos\beta_F \right\rfloor}
```

**`latex` 裝得下它的外觀。裝不下的是它的意義**——原文未說明 `→1`／`→0` 代表什麼
條件下的退化。依 CLAUDE.md「標記它，不要補全它」，這屬 `issues.kind:
undefined_in_source`，是既有機制，**不是 schema 缺口**。

W0.7 當時的標記是謹慎的，但結論應修正為：schema 無需為此擴充。

## 4　意外發現：`data/modules.yaml` 有系統性錯誤

> **已於同日修正。** 附錄 A 全部 282 頁的頁首條帶逐頁目視重新驗證，結果寫入
> `data/modules.yaml`：29 個 subsystem、符號表 134 頁。本節保留當時查到的內容，
> 因為值得記住的不是「7B 漏了」，而是**錯誤的類型**——把「方框摘要頁」當成
> 「符號表頁」。W5.2 重建本檔時可能再犯同一個混淆。

### 4.1　Subsystem 7B 整個缺漏

`modules.yaml` 只有 `7A`，範圍 pdf 171–190。實際上：

| | 實際 | `modules.yaml` |
|---|---|---|
| 7A　LANDING GEAR (Present Sigma 8 Model) | pdf **171–184** | 171–190 |
| 7B　LANDING GEAR (Unused Bell Model) | pdf **185–190** | **不存在** |

證據：pdf 185 為方框頁「7B LANDING GEAR (Unused Bell Model)」，pdf 186／187 頁首為
「SUBSYSTEM NO. 7B—LANDING GEAR」與「(Concluded)」，pdf 191 起才是 8a CONTROLS。

**全書不是 27 個 subsystem。**（當時判為 28，全書重驗後為 29，見 §4.3。）
事後看，`7A` 存在而無 `7B` 本身就該是警訊——
文件的編號慣例支援子字母（`8a`–`8d`、`10a`–`10e` 皆成對出現）。

### 4.2　`io_summary_pages` 系統性少計

符號表不只出現在方框頁，還延續到其後**無方框**的「SUBSYSTEM NO. X: …
(CONTINUED)／(CONCLUDED)」頁面。`modules.yaml` 只收了方框頁。

以 Subsystem 11 為例：

| pdf | 頁首 | 內容 | 在 `modules.yaml`？ |
|---|---|---|---|
| 270 | 方框「11 AIRCRAFT ANGULAR…」 | 符號表 | ✓ |
| 271 | 方框「…(CONCLUDED)」 | 符號表 | ✓ |
| 272 | SUBSYSTEM NO. 11: … | 符號表 | **✗** |
| 273 | SUBSYSTEM NO. 11: …(CONTINUED) | 符號表 | **✗** |
| 274 | SUBSYSTEM NO. 11: …(CONCLUDED) | 符號表 | **✗** |
| 275 | EQUATIONS / SUBSYSTEM 11— | 公式 | — |

記錄 2 頁，實際 5 頁。同樣情形已在 7A（171–172，記 1 頁）與 7B（185–187，未記）確認。

### 4.3　後果與處置

重新驗證的作法是以 `tools/strip_sheet.py` 將 pdf 69–350 全部 282 頁的頁首條帶
拼成 12 張圖逐頁目視。**未採用 `tools/section_scan.py` 的自動分類**——該分類在
24 頁樣本上錯 4 頁（`boxed` 會誤命中有外框的公式頁，又漏掉真正的方框頁），
推及全書約 48 頁會錯。

| 項目 | 修正前 | 修正後 |
|---|---|---|
| subsystem 數 | 27 | **29**（新增 7B、10f） |
| 符號表頁合計 | 44 | **134** |
| W2.3 估時 | 8 h | 24 h |

兩項尚未處理：

- **`scope` 命名空間需含 `7B` 與 `10f`**，於 G3 定案時納入。
- **W0.3／W0.4 的其餘統計未重算。** `equation_pages` 欄本即註明為「首行置中的頁數，
  圖版頁亦會計入」之上界估計。決議 #1 選定 subsystem 4 的依據來自該欄，
  但 subsystem 4 的頁範圍（113–145）未受本次更正影響，故決議不變。
